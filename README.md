# AnionCode

Platform sederhana untuk belajar dan berbagi kode.

## 📁 Struktur Project

```
anioncode/
├── index.html      # File HTML utama
├── style.css       # Styling CSS
├── script.js       # JavaScript functionality
└── README.md       # File ini
```

## 🚀 Cara Menjalankan

1. Clone repository ini
2. Buka file `index.html` di browser Anda
3. Atau gunakan Live Server (jika menggunakan VS Code)

## ✨ Fitur

- ✅ Navbar dengan navigation
- ✅ Hero section dengan CTA button
- ✅ About section dengan feature cards
- ✅ Contact form
- ✅ Responsive design
- ✅ Smooth scrolling

## 📝 Rencana Pengembangan

Berikut ini bisa Anda tambahkan nanti:

- [ ] Backend dengan Node.js/Python
- [ ] Database untuk menyimpan pesan contact
- [ ] Authentication system
- [ ] Blog atau artikel section
- [ ] User dashboard
- [ ] API untuk berbagi code snippets
- [ ] Dark mode
- [ ] Lebih banyak interaktivitas dengan JavaScript

## 💡 Tips untuk Lanjutan

1. Tambahkan backend framework (Express.js, FastAPI, dll)
2. Integrasikan dengan database (MongoDB, PostgreSQL, dll)
3. Deploy ke hosting (Netlify, Vercel, Heroku, dll)
4. Tambahkan testing
5. Implement CI/CD pipeline
